Penghapusan data Luca AI

Aplikasi: Luca AI
Pengembang: KANZAPRO71
Nama paket: com.luca.ai
Terakhir diperbarui: 29 September 2026

Luca AI tidak membuat akun pengguna dan tidak menyimpan percakapan di server pengembang. Data yang ada di ponsel dihapus oleh Anda, lewat langkah di bawah. Tidak ada masa penyimpanan tambahan di server Luca, karena salinan server itu tidak ada.

Catatan di perangkat

  1. Buka Luca AI.
  2. Buka Catatan.
  3. Ketuk catatan yang ingin dihapus.
  4. Ketuk Hapus catatan, lalu konfirmasi.

Catatan itu terhapus dari perangkat. Pengembang tidak menyimpan salinannya.

Memori yang Luca ingat

  1. Buka Luca AI.
  2. Buka pengaturan, bagian Yang Luca ingat.
  3. Ketuk Hapus pada memori yang ingin dihilangkan.

Memori yang dihapus tidak lagi dipakai di sesi berikutnya. Pengembang tidak menyimpan salinannya.

Semua data Luca di ponsel

Hapus pemasangan aplikasi Luca AI dari Android. Ini menghapus catatan, memori, pengaturan, dan kunci API yang Anda ketik sendiri, beserta data Luca lain di perangkat itu. Tindakan ini tidak dapat dikembalikan dari sisi pengembang.

Audio yang sudah terkirim ke Google

Saat sesi suara berjalan, audio mikrofon dikirim ke Gemini API milik Google agar Luca dapat membalas. Pengembang Luca tidak menyimpan audio itu dan tidak memiliki masa retensi untuk audio tersebut.

Salinan yang diproses Google mengikuti ketentuan Gemini API dan Kebijakan Privasi Google, bukan jadwal penyimpanan Luca. Pada rilis pengujian, permintaan itu lewat proyek Google milik pengembang. Pengembang tidak menyimpan transkripnya sebagai basis data pengguna.

Jika Anda tetap ingin menghubungi pengembang

Tidak ada akun yang bisa ditutup. Untuk pertanyaan penghapusan, kirim pesan lewat github.com/KANZAPRO71 dan tulis bahwa permintaan itu untuk aplikasi Luca AI. Sebutkan jenis data yang Anda maksud. Karena pengembang tidak menyimpan akun atau salinan percakapan, permintaan itu tidak menghapus data di ponsel Anda. Data di ponsel tetap dihapus lewat langkah di atas.

Kebijakan Privasi Luca AI

Delete your Luca AI data

App: Luca AI
Developer: KANZAPRO71
Package name: com.luca.ai
Last updated: 29 September 2026

Luca AI does not create user accounts and does not store conversations on a developer server. Data on the phone is deleted by you, using the steps below. There is no extra retention period on a Luca server, because that server copy does not exist.

Notes on the device

  1. Open Luca AI.
  2. Open Catatan (Notes).
  3. Tap the note you want to remove.
  4. Tap Hapus catatan (Delete note), then confirm.

That note is deleted from the device. The developer does not keep a copy.

Memory Luca keeps

  1. Open Luca AI.
  2. Open settings, section Yang Luca ingat (What Luca remembers).
  3. Tap Hapus (Delete) on the memory you want removed.

Deleted memory is not used in later sessions. The developer does not keep a copy.

All Luca data on the phone

Uninstall Luca AI from Android. This removes notes, memory, settings, and any API key you typed, along with other Luca data on that device. The developer cannot restore it.

Audio already sent to Google

During a voice session, microphone audio is sent to Google’s Gemini API so Luca can reply. The Luca developer does not store that audio and has no retention period for it.

Copies processed by Google follow the Gemini API terms and the Google Privacy Policy, not a Luca retention schedule. In the test build, those requests go through the developer’s Google project. The developer does not keep the transcript as a user database.

If you still want to contact the developer

There is no account to close. For a deletion question, message github.com/KANZAPRO71 and say the request is for the app Luca AI. Name the type of data you mean. Because the developer does not store an account or a copy of the conversation, that message does not delete data on your phone. Phone data is still deleted by the steps above.
